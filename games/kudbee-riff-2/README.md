# Kudbee Riff II — Neon Fret Rush

> **Kudbee Games Studio** — second track in the Riff series. Same four-lane fret-rush engine
> as [Kudbee Riff](../kudbee-riff/), with its own `assets/analysis.json` chart.

## Play

- **Hosted:** `/games/kudbee-riff-2/index.html`
- **Locally:** `python3 -m http.server 8000` →
  <http://localhost:8000/games/kudbee-riff-2/index.html>

## Controls

Same as Riff: **`D F J K`** lanes, **`Space`** / heat bar for Overdrive, **`P`** pause.
Touch: tap lanes and the heat bar.

See [`../kudbee-riff/README.md`](../kudbee-riff/README.md) for leaderboard and career details.
SDK game id: **`riff-2`**.
